# 易签 · 易班签到小助手

> 图形界面 + 命令行双形态的易班自动签到工具：多账号、定时签到，目前支持**校本化**与**易伴云**两种签到方式
> 自动处理定位、图片签到、验证码与结果通知，并内置自动更新。

- **下载即用**：单文件程序，免安装（Windows / Linux / macOS Intel，另有 Linux 无界面版）
- **看得见**：账号表格 + 运行日志 + 一键批量操作，签到结果一目了然
- **跑得住**：自动等签到时间段、自动处理验证码、自动更新

---

## 一、它能做什么

**签到能力**

- 校本化签到：自动获取签到时间 → 到点自动提交 → 回报签到名次与时间
- 易伴云签到（易班 App 内签到分支）：同样支持自动时间与自动提交
- 两种入口都支持**上传图片签到**（校本化 / 校外）
- **销假**：查询剩余次数并提交
- **多账号、多学校**同时进行（多线程），互不干扰

**账号与操作**

- 一个界面管理全部账号：添加、编辑、启用 / 停用、删除
- 「批量测试账号」：只验证登录是否可用，**不签到**
- 「获取签到状态」：只查"今天签没签 + 签到时间 + 名次"，不提交任何内容
- 右键单个账号：单人签到 / 销假

**定位**

- 自动获取（服务端签到范围内随机取点，更接近真实位置）
- 固定经纬度（手动填，或**地图选点**一次点好，坐标保留 6 位小数）
- 范围外原因（签到点在范围外时随签到一起提交）

**验证码**

- 登录触发数美验证码时，自动打开一个独立浏览器窗口，完成后**窗口自动关闭**（仅windows平台）
- 可以用手机连同一 Wi-Fi 完成验证；也可以固定验证码端口
- 验证码任务串行进行，不会一屏弹一堆窗口

**通知**

- pushplus 推送、邮件通知（SMTP，支持 SSL / STARTTLS）
- 签到结果、失败原因、验证码提醒都会通知到位

**其它**

- 自动更新（校验完整性后自动替换并重启）
- 运行日志可复制、可导出；界面卡住时自动留下现场文件
- 整机级单实例：不会误开成两个程序互相抢数据

## 三、三分钟上手

1. **下载**：到[发布页](https://github.com/2117516450/yiban_signin/releases)下载对应平台的文件。
   Windows 双击 exe 即可；Linux 先 `chmod +x` 再运行；macOS 打开 DMG 把 `易签.app` 拖进「应用程序」。
   建议放在**一个独立目录**里（配置、日志、图片都存在它旁边，备份整目录即可）。
2. **首轮引导**：第一次启动会带你走四步 —— 阅读告知文本 → 配置通知（可先跳过）
   → 添加第一个账号 → 完成。
   【此处首轮引导截图】
3. **添加账号**：点「添加账号…」，填易班手机号与密码，选签到方式（校本化 / 易伴云），
   需要时设置延时与定位。填完可以点「账号测试」确认能登录。
4. **勾选账号**：在列表里勾选要操作的账号；不勾选时，大多数操作会先问一句"是否对全部执行"。
5. **开始签到**：点「开始签到」，程序会自动等到签到时间段再执行，跑完按你的配置发通知。
6. **看结果**：界面日志里能看到每个账号的结论（如 `今天 09-23 07:12 已签到，第 5 名`），
   同时手机 / 邮箱会收到通知。

**常用按钮**

| 按钮 | 作用 |
| --- | --- |
| 批量签到 | 对勾选的账号执行签到（会自动等待签到时段） |
| 批量测试账号 | 只验证登录是否可用（**不签到**），用来检查账号 / 密码 |
| 获取签到状态 | 只查"今天签没签 + 签到时间 + 名次" |
| 停止 | 立即停止任务、取消全部验证码、关闭数据库 |
| 添加账号… | 新增账号（右键账号可编辑 / 停用 / 删除 / 单人签到 / 销假） |

## 四、功能怎么用（逐项说明）

### 1. 添加与管理账号

- 点「添加账号…」填写**易班手机号 + 密码**，选择**签到方式**：
  - **校本化**：学校自己的签到系统（大部分学校是这种）；
  - **易伴云**：易班 App 内的签到分支；
  - 两个都勾选也可以，程序会按顺序都尝试。
- 「账号测试」只跑登录，**不签到**，用它确认密码 / 令牌是否有效。
- 账号列表支持右键：编辑、停用 / 启用、单人签到、销假、删除。
- 同一个账号可以配置**签到延时**（在签到时间段内随机往后延，避免所有人都在同一秒提交）。

### 2. 定时签到是怎么跑的

1. 程序先查询该账号今天的签到时间段；
2. 如果还没到时间，就**自动等待**（界面上会显示倒计时），到点前会刷新一次登录票据；
3. 到点后自动取位置 → 提交签到（需要图片的会带图片）→ 记录名次与时间；
4. 全部结束后按你的配置发送结果通知。
5. 中途想停：点「停止」即可。

### 3. 定位怎么设置

| 方式 | 什么时候用 |
| --- | --- |
| **自动获取**（默认） | 让程序在服务端下发的签到范围内自动取点，最省事 |
| **固定经纬度** | 你知道要在某个具体点签到（比如宿舍、教学楼）；坐标保留 **6 位小数** |
| ↳ **地图选点** | 不想手敲坐标：点【地图选点…】→ 在地图里搜索或点选地点 → 点「确认选择」→ 自动填好经纬度与地址，**窗口自动关闭**；之后签到固定用这个地址 |
| **范围外原因** | 当签到点在范围外时填写（例如"人在外地实习"），会随签到一起提交（不推荐使用） |

【此处定位与地图选点截图】

> 地图选点需要一个 Chromium 系浏览器：**Windows 10/11 自带的 Edge 就能用**（Chrome / Brave 也行）。
> 如果机器上确实没有这类浏览器，选点页会退回系统默认浏览器打开（浏览器需要你手动关闭），
> 页面右侧也提供"经纬度及地址详细信息"。

### 4. 图片签到

- 需要图片签到的学校，要在账号设置里指定**个人图片**（或使用全局默认图片）；
- 图片要求以学校规定为准（一般要求本人在签到点拍摄、能看清门牌等）；
- 程序会在提交时自动带上图片，无需每次手动选择。

### 5. 验证码怎么完成

1. 登录触发数美验证码时，程序会**自动打开一个独立的浏览器窗口**（与你日常浏览器互不干扰），
   同时界面弹出一个提示窗；
2. 你在那个窗口里完成验证（空间点选）；
3. 验证通过后，**浏览器窗口和程序提示窗都会自动关闭**，程序继续下一个账号。

要点：

- 验证码**串行**：同一时刻只处理一个账号；
- 单个账号超时 **120 秒**，超时自动切下一个；
- 日志里有**本机链接**和**局域网链接**，可以用手机连同一 Wi-Fi 完成验证；
- 可以在设置里**固定验证码端口**；
- 验证码**邮件**提醒（发给你的发信邮箱，正文含完整账号、不带链接）；
- 拿不到验证码，这个账号本次就是失败，程序不会静默跳过。

### 6. 通知怎么配

- **pushplus**：填 32 位 token 并勾选启用（需在 pushplus 侧实名认证，其收费与本项目无关）；
- **邮件**：填 SMTP 域名、加密方式（SSL / STARTTLS）、端口、账号、密码 / 授权码，
  可点「发送测试邮件」确认配置是否正确；
- 通知内容包含：每个账号签到成功 / 失败、失败原因、签到时间与名次；
- 验证码提醒会在需要你操作时立刻发出。

### 7. 结果与日志怎么看

- 日志区按级别着色，支持**复制 / 全选**，也可以导出；
- 签到结论会明确写出**哪一天**：`今天 09-23 07:12 已签到，第 5 名` / `昨天 09-22 07:12 已签到` /
  `今日已签到（服务器没给签到时间）`；
- 失败会给出原因（定位失败 / 需要验证码 / 范围外需要原因 / 图片未配置 …），照着补就行。

### 8. 自动更新

- 启动时自动检查更新，有新版本会提示；你确认后就地替换并**自动重启**到新版本；
- 某些版本可能是**必需更新**，需要更新后才能继续使用；
- macOS 会把 App 安装到「应用程序」（目录不可写时退回 `~/Applications`）。

### 9. 单实例与多开

- 程序是**整机级单实例**：同一台电脑只能开一个（换目录、换 Windows 用户都不行）；
- 再开一个只会提示"程序已在运行中"，不会抢你的数据；
- 自动更新时新版会自己接替旧进程，正常看不到这个提示。

### 10. 数据与备份

程序所在目录里：

| 文件 / 目录 | 内容 |
| --- | --- |
| `yiqian.db` | 账号、签到记录、设置（本地加密数据库） |
| `pic/` | 账号图片（个人图 / 全局默认图） |
| `log/` | 运行日志 |
| `卡死诊断_*.log` | 界面卡住时自动留下的现场（排查用） |

备份：整个目录拷走即可；换机器时拷回来，程序会自动读取。

## 五、常见问题（FAQ）

**Q：弹出"程序已在运行中"？**
A：本程序是整机级单实例，先关掉已打开的窗口即可，不支持多开；自动更新时新版会自己接替旧进程。

**Q：没有装 Chrome，能用地图选点和验证码窗口吗？**
A：能。程序优先找 **Edge**（Win10/11 自带），其次 Chrome / Chromium / Brave；
三种都找不到时会退回系统默认浏览器打开（能用，但那个标签页要手动关）。

**Q：服务器没有图形界面，会报错吗？**
A：不会。请使用**无界面版**（`yiqian_cli_*`）：它不依赖图形环境，验证码链接会出现在日志里；
"独立浏览器窗口 / 地图选点"属于图形界面功能，无界面环境不会去调用。
推荐先在GUI下配置，再将同目录下的**yiqian.db**复制到服务器上，可以节省配置时间

**Q：收不到通知？**
A：① 设置里对应渠道要打开（pushplus 要填 32 位 token；邮件要填域名 / 端口 / 账号 / 授权码）；
② 点「发送测试邮件」确认配置；③ 任务还没跑完时不会有结果通知。

**Q：签到失败怎么办？**
A：看日志里的原因提示（定位失败 / 需要验证码 / 范围外需要原因 / 图片未配置 …），按提示补齐即可；
也可以先用「批量测试账号」确认账号本身可用。

**Q：日志里会不会泄露敏感信息？**
A：默认日志已做脱敏（密码、令牌等不会明文出现）。
